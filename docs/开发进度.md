### 实际修改（P3）

- 权限纯函数：`NONE+READ=READ`、`READ+FULL=FULL`、未发布/未知/等级不足拒绝（含超级管理员）。
- IAM 本地 `require_permission(resource, action)`；不缓存允许结果。
- `POST /internal/v1/authorize`：校验 `X-Internal-Service` + `X-Internal-Token`，
  只用调用方传入的用户 Access Token 解析身份，拒绝 body 里的 `user_id`。
- `platform_common.authz.AuthzClient`：连接池 + 超时；5xx/网络失败 → 503，不允许。
- 用户/角色/资源树/授权接口按架构 11.2 落地；写 DTO `extra=forbid`。
- 禁用、重置密码、强制下线撤销会话；乐观锁 `version` 冲突 409。
- 普通角色不能获得 `system.permissions`；内置角色不能改状态；
  最后可登录超级管理员保护（事务内 `FOR UPDATE`）。
- `GET /auth/permissions` 返回有效资源等级与可见菜单（未发布不进导航）。
