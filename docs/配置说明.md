# 配置说明

真实密钥只放在本机 `.env` 或密钥目录，不提交仓库。`.env.example` 只提供字段清单和演示值。

## 环境标识

| 值 | 用途 |
| --- | --- |
| `development` | 本地 Compose / `pnpm dev` |
| `test` | 隔离验收栈（P6） |
| `production` | 生产模板；演示密钥会被拒绝启动 |

各服务环境变量前缀：IAM 用 `IAM_`，审计用 `AUDIT_`。

## 必填项

| 变量 | 说明 |
| --- | --- |
| `POSTGRES_SUPERUSER` / `POSTGRES_SUPERUSER_PASSWORD` | 仅初始化脚本用，应用不使用 |
| `IAM_DB_*` / `AUDIT_DB_*` / `CODEBOOK_DB_*` | 各自独立库与账号 |
| `AUDIT_CLEANUP_DB_USER` / `AUDIT_CLEANUP_DB_PASSWORD` | 到期清理专用账号 |
| `IAM_INTERNAL_CALLER_SECRETS` | 调用 IAM 内部接口的服务名→密钥 |
| `IAM_AUDIT_INGEST_SECRET` | Worker 写审计的内部密钥 |
| `AUDIT_INTERNAL_CALLER_SECRETS` | 允许写审计的服务名→密钥 |
| `AUDIT_IAM_SERVICE_SECRET` | 审计查询时调 IAM 授权的密钥 |

JWT 私钥目录：`deploy/secrets/jwt`（gitignore）。`make bootstrap` / `make jwt-keys` 会生成开发密钥。

## 会话与安全默认值

- Access Token 900 秒，Refresh / 会话 7 天，算法 RS256。
- Refresh Cookie：`HttpOnly`，`Path=/api/v1/auth`，`SameSite=strict`。
- 登录失败默认 5 次 / 300 秒；Redis 不可用时登录返回 503。
- 审计默认保留 180 天，由 `AUDIT_RETENTION_DAYS` 调整。

## 端口（本地）

| 用途 | 开发默认 | P6 隔离栈 |
| --- | --- | --- |
| 网关 | `GATEWAY_HTTP_PORT=8080` | `8090` |
| PostgreSQL 宿主机映射 | `5433` | `5434` |
| Redis 宿主机映射 | `6380` | `6381` |

服务端口、数据库、Redis 不得对公网暴露。生产只公开网关 443，见 `deploy/gateway/traefik.prod.yml.example`。

## 隔离验收栈

`deploy/compose/p6.env.example` → `deploy/compose/.p6.env`。库名必须是 `*_p6_db`，避免备份/恢复误伤开发库。

内部 JSON 密钥在 Compose 里写成 YAML 单引号字面量。不要写 `${VAR:-{"k":"v"}}`：Compose 会把第一个 `}` 当成插值结束，容器里只剩 `{`，服务无法启动。
