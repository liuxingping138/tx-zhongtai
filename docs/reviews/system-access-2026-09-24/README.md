# 系统管理与个人设置 UI/UX 复查（2026-09-24）

## 范围与方法

在 `http://localhost:8080` 的实际 Docker 页面，以 1280×720 和 1024×768 查看用户管理、角色与权限、操作日志、左下角账号菜单和个人设置。核对「新增用户 → 分配角色 → 查看实际权限」「新增角色 → 权限设置 → 成员」的入口、只读限制、日志追溯和个人改密/会话操作。没有创建用户、修改任何实际授权、输入密码或执行全设备退出。当前开发库只有一个内置超级管理员角色，因此自定义角色的实际保存与授权效果未在此库执行。

## 可配置范围

当前已发布模块的角色授权与人员分配可通过页面完成：一个人可有多个角色，实际权限取最高档；资源权限支持查看、导出、管理，后端也实施鉴权。按现行安全规则，**只有超级管理员能分配角色和权限**，`权限分配` 资源不能授予普通角色。未来客户、招投标等新模块仍需先实现页面、API 和资源目录，再进入此权限树；页面配置负责已登记资源的授权，不是从页面生成业务模块。
