# 顶部导航截图对照

本轮仅审查导航外壳，不修改首页或业务界面。用户问当前预览是否存在视觉不协调。

1. 参考原型：结构较清楚。左侧品牌区约 240px，与下方侧栏对齐；右侧标题与横向模块组成独立顶栏。截图 01-reference-top-audit.png。
2. 当前信源预览：可用但结构不够协调。DOM 测量侧栏宽216px，品牌区域宽296px（x26—322），模块导航从x354开始，内容从x216开始。截图 02-current-top-audit.png。

主要问题：品牌区与侧栏边界未对齐；一级导航与左侧菜单的横向起点缺乏关联；侧栏重复分组名，又叠加圆角底、左边线和箭头；页头/模块文字与较小的工具文字形成较强落差。右上两个预览控件是评审工具，也增加了视觉噪声，正式版不应保留。

建议优先统一侧栏和品牌区的布局边界，平台标题/一级模块在右侧有序排列；二级菜单收敛为一套选中提示，统一主色与字号层级。保留顶部模块、左侧子模块的信息架构。首页内容继续不改。

边界：两份全屏截图同为1280px宽，高度分别800与720；比较的是顶部与侧栏结构，不比较业务内容、图表或可见行数。补拍的header-detail截图被工具缩放，未作为结论依据。不据截图声明完整无障碍合规；小字号仅列为可读性风险。
