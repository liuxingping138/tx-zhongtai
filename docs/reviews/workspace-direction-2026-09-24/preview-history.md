## 历史探索记录

以下观察与验证保留早期方向的历史，不代表当前布局；工作台样板已按用户最新要求移除。

## 观察与优先级

- P1 产品辨识度：深色侧栏、灰底白卡、等权入口网格，无法表达业务平台的关系与层次。
- P1 空间分配：树状菜单长期占用横向空间；大字段表格更需要宽度。尝试窄业务导航 + 顶部模块导航。
- P2 首页信息：所有入口都写相近的“查看与维护数据”，缺少具体用途。改用任务语义、真实可访问模块和独立的产品规划示意。
- P2 视觉节奏：标题、模块、操作、数据缺少区分。首页承担产品表达；列表保持克制的工作界面。

## 方向：业务情报工作台

设计主张：以连接关系构成视觉记忆，而不是给通用后台增加装饰卡片。唯一突出图形是首页的业务关系图；仅用于解释产品规划，不代表现有数据关联已经实现。

配色：墨蓝 #162638（导航/重点文字）、钴蓝 #3558de（主操作）、青绿 #087f72（独立采集能力）、雾灰 #f4f6f8（画布）、白 #ffffff（工作面）、灰蓝 #5f6c7b（次级文字）。不下载字体：中文展示字使用 PingFang SC/Microsoft YaHei 600，正文 14px，数字/序号使用 SFMono-Regular/ui-monospace。

布局草图：

```text
窄业务栏 | 品牌、当前分区、模块查找、预览标识
         | 当前分区的模块导航（真实权限过滤）
         | 首页：业务关系与规划 + 可访问工作入口
         | 列表：标题 → 全部筛选 → 操作栏 → 全字段结果
账号菜单 |                                  分页
```

自我审查：只改色板依然会像通用后台，因此先改变导航层级与首页组织；避免过度追求“惊艳”导致列表空间变小，列表不增加大图和营销标题。原有一列一字段、默认全部字段、列设置、Excel 上传下载、权限守卫继续复用。

## 隔离方式

运行已有开发服务 `cd frontend && pnpm dev --host 127.0.0.1`，打开 http://localhost:5173/?design-preview=1 。只在 Vite 开发环境且指定预览参数时启用，生产构建不切换界面。采用后端已允许的 5173 开发端口，不放宽 Origin 安全规则。预览复用既有身份认证、权限、API 和业务组件；有真实操作能力，验证仅执行读取及可逆界面操作，不修改业务记录。

预览专有文件在 `frontend/src/design-preview/`，尚不是第二套生产组件规范。方向确认后应把被采纳的部分合并到现有 canonical 组件并同步正式文档，删除探索分支。

- 生产产物未包含 WorkspaceLayout / WorkspaceHome 或预览 CSS；8080 未重建，保留当前界面用于比较。
