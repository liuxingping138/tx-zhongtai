## 列设置补充

根据用户反馈，将不易发现的齿轮入口改为“列设置 已选/全部”。行业场景默认4个数据列，31个业务字段加4个系统字段，共35个可选列，操作列始终保留。新增“显示全部列”（全选）与“恢复默认列”；偏好按用户和页面保存在本浏览器。内置浏览器已观察到35/35和36个表头（含操作），全部原有字段可达。截图见 `after-column-settings.jpg`。

用户反馈政策列表第一列的灰字含义不清后，取消信源/基础标签/解读第一列中的部门或行业副文本，保持一列一字段；这些数据仍可独立勾选成列或在详情查看。

最终统一要求：所有列表一列一个字段。已从共享 BusinessTable 中删除辅助字段展示能力，码表下方的编码等也不再混排；需要的字段使用列设置独立展示。
