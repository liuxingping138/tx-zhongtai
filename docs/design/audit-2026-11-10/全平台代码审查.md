## 三、前端与 E2E 修复（`frontend/`）

1. **E2E 适配用户详情页改版**：更新 `frontend/e2e/module-regressions.spec.ts` 中权限穿透表断言（从旧的 `.perm-line` 改为 `.perm-table .data-row` / `.source-badge`）。
2. **用户详情页状态与并发修复**（`UserDetailPage.vue`、`UserInfoForm.vue`、`UserRoleAssign.vue`）：
   - 分离「基本资料」与「角色配置」的 `saving` / `saveError`，互不串错；
   - 角色保存成功但刷新实际权限失败时，仅在右侧权限表提示失败，不再误报角色保存失败；
   - 编辑基本资料期间收到角色/授权保存带来的 `user` 更新时不覆盖未保存草稿；
   - 监听 `userId` 路由参数变化重加载并清理旧错误提示；为 `grantsSaved` 补上 `.catch`；
   - 通过 `@dirty` 事件将未保存角色变更状态同步到 `EffectivePermissions` 的 `pendingRoleChange`。
3. **清理死代码**：移除 `UserList.vue` 中不再使用的 `UserDetailDrawer` 引用与无用状态。
4. **个人设置页数据与响应式修复**（`ProfileView.vue`）：无角色时如实显示 `0 个 / 暂无分配角色`，安全状态与账号禁用提示随 `isActive` 联动；修复 1024px 媒体查询中对 flex 容器误用 `grid-template-columns` 导致的统计卡片溢出。
5. **改密页与服务不可用页**（`ChangePasswordView.vue`、`UnavailableView.vue`）：非强制改密时标题与按钮文案区分「修改登录密码 / 保存新密码」，无历史栈时返回首页；`UnavailableView.vue` 校验 `redirect` 拒绝 `//` 协议相对跳转。
